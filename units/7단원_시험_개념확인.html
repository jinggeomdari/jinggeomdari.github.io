1문자의 사용

곱셈 기호의 생략

수와 문자, 문자와 문자의 곱에서는 곱셈 기호 ×를 생략한다.

수와 문자의 곱은 수를 문자 앞에 쓴다. 5 × a = 5a
1과 −1

문자에 곱한 1은 생략하고, −1을 곱하면 −a로 쓴다.

문자끼리의 곱은 보통 알파벳 순서대로 쓰고, 같은 문자의 곱은 거듭제곱으로 나타낸다.

b × a = ab,  a × a = a2

2나눗셈 기호의 생략

분수로 표현

나눗셈 기호 ÷를 생략하고 분수의 꼴로 나타낸다.

a ÷ b = ab (단, b ≠ 0)

곱하거나 나누는 대상이 식 전체라면 괄호와 분수선을 분명히 표시한다.

4항과 다항식

항

수 또는 문자의 곱으로 이루어진 것

상수항

수만으로 이루어진 항

계수

항에서 문자에 곱해진 수

다항식

한 개 또는 두 개 이상의 항의 합으로 이루어진 식

단항식

항이 한 개뿐인 다항식

2x + 5의 항은 2x와 5, 상수항은 5, x의 계수는 2이다.

5차수와 일차식

차수

일차식

차수가 1인 다항식

2x + 5는 일차식이고, 3x2의 차수는 2이다.

9지수법칙

m, n은 자연수이다. 나눗셈에서는 밑이 0이 아니어야 한다.

밑이 같은 거듭제곱의 곱

am × an = am+n

지수를 더한다.

거듭제곱의 거듭제곱

(am)n = amn

지수를 곱한다.

밑이 같은 거듭제곱의 나눗셈

am ÷ an = 지수의 크기에 따라 계산

밑이 0이 아니어야 한다.

곱과 몫의 거듭제곱

(ab)m = ambm
(ba)m = bmam

나눗셈: m > n

am ÷ an = am−n

나눗셈: m = n

am ÷ an = 1

나눗셈: m < n

12다항식의 덧셈·뺄셈

뺄셈에서는 빼는 식의 각 항의 부호를 바꾸어 더한다.

(2a + 3b) + (4a − b) = 6a + 2b

Ⅲ. 다항식의 곱셈과 인수분해

16다항식의 곱셈

다항식의 각 항을 상대 다항식의 각 항에 곱한 뒤 동류항끼리 모은다.

(a + b)(c + d) = ac + ad + bc + bd

17곱셈공식

① 합의 제곱

(a + b)2 = a2 + 2ab + b2

② 차의 제곱

(a − b)2 = a2 − 2ab + b2

③ 합과 차의 곱

(a + b)(a − b) = a2 − b2

④ 최고차항이 x²

(x + a)(x + b) = x2 + (a+b)x + ab

⑤ 계수가 있는 일차식의 곱

(ax+b)(cx+d) = acx2 + (ad+bc)x + bd

18인수분해

인수

다항식을 곱으로 나타낼 때 각 식

인수분해

한 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것

x2 + 3x + 2 ⇄ (x + 1)(x + 2)

19공통인수

각 항에 공통인 인수가 있으면 분배법칙을 거꾸로 이용해 묶는다.

ma + mb = m(a + b)

20인수분해 공식

① 완전제곱식

a2 + 2ab + b2 = (a + b)2

② 완전제곱식

a2 − 2ab + b2 = (a − b)2

③ 제곱의 차

a2 − b2 = (a + b)(a − b)

④ 합과 곱을 찾기

x2 + (a+b)x + ab = (x + a)(x + b)

⑤ 계수가 있는 경우

acx2 + (ad+bc)x + bd = (ax+b)(cx+d)

완전제곱식은 다항식의 제곱으로 이루어진 식 또는 그 식에 수를 곱한 식이다.

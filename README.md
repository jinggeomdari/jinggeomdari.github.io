# 징검다리 개념 확인

고등학교 1학년 수학 단원마다 필요한 중학교 개념을 정리 · 퀴즈 · 게임으로 확인하는 단원별 HTML(1~6단원)을 표지 하나로 묶은 사이트입니다.

**사이트: https://jinggeomdari.github.io/** (주소 끝에 `#u3`을 붙이면 3단원이 바로 열립니다)

단원 파일은 **고치지 않고 그대로** 들어가고, 표지 카드의 색·차례·빈칸 수도 단원 파일에서 읽어 옵니다.
그래서 단원 담당자가 `units/` 폴더에 새 파일을 올리기만 하면 1~2분 뒤 사이트가 저절로 바뀝니다.

## 단원 담당자: 새 버전 올리기

1. 이 저장소의 [`units`](units) 폴더를 엽니다.
2. 오른쪽 위 **Add file → Upload files** → 단원 파일을 끌어다 놓기 → 아래 **Commit changes**.
   - 파일 이름은 `3단원_….html`처럼 **번호+단원**으로 시작해야 합니다. 이름은 달라져도 됩니다(`_1030` 등).
   - 이름이 같으면 옛 파일이 바뀌고, 이름이 다르면 같은 번호 중 **가장 나중에 올린 파일**이 쓰입니다.
     헷갈리지 않게 옛 파일은 지워 주세요 (파일을 열고 ⋯ → **Delete file**).
3. 위쪽 **Actions** 탭에서 결과를 봅니다.
   - 초록 체크 ✓: 반영 완료. 실행 기록을 열어 맨 위에 **노란 경고 ⚠**가 있으면 읽어 주세요.
     이름이 규칙에 안 맞거나 `units` 폴더 밖에 올린 파일은 **사이트에 쓰이지 않고** 여기에 "쓰지 않은 파일"로 나옵니다.
     단원 파일의 스크립트 오류(브라우저 검사)도 여기에 나옵니다.
   - 빨간 X: 파일이 잘렸거나 개념확인 파일이 아니라서 반영하지 않았습니다. **지금 사이트는 그대로**입니다. 고친 파일을 다시 올리면 됩니다.
4. 잘못 올렸으면 예전 파일을 다시 올리면 됩니다. 올린 기록은 모두 남아 있습니다 (파일 열기 → **History**).

## 결과물

- **웹판**: 위 사이트. 단원을 누를 때 그 단원만 내려받아 휴대폰에서도 빠릅니다.
- **한 파일판**: 사이트 표지 맨 아래 **한 파일판 내려받기**. 단원 6개가 모두 든 HTML 한 개라 카톡·USB로 나눠 주고 인터넷 없이 엽니다.

## 관리자: 내 컴퓨터에서 만들어 보기

`빌드.cmd`를 더블클릭하면 `dist/`에 두 판이 만들어지고 각 단원을 Chrome으로 열어 검사합니다 (Node.js 필요).
다른 폴더(예: 카톡 받은 파일 폴더)를 `빌드.cmd` 위에 끌어다 놓으면 그 폴더의 단원 파일로 만듭니다.
명령으로는 `node build.mjs`, `node check.mjs`.

| 경로 | 내용 |
|---|---|
| `units/` | 단원 파일 원본 |
| `hub.html` | 표지·단원 보기 틀. 디자인을 고칠 때만 수정 |
| `build.mjs` | 통합본 만들기. 맨 위 `NAMES`에 고등 단원 이름 |
| `check.mjs` | 단원 파일을 Chrome으로 열어 오류 찾기 (배포는 막지 않음) |
| `.github/workflows/deploy.yml` | 파일이 올라올 때마다 만들어 GitHub Pages에 올리기 |

담당자 초대: 저장소 **Settings → Collaborators and teams → Add people**에 GitHub 아이디를 넣고 **Write** 권한을 줍니다.
담당자가 웹에서 올린 커밋에는 그 담당자의 아이디가 표시됩니다.
이 폴더에서 올리는 커밋은 작성자가 "징검다리"로 표시되도록 설정되어 있습니다 (`git config user.name`).

## 단원 파일에서 표지가 읽는 부분

단원 템플릿(수학 개념 게임 저장소의 `새단원_만들기_프롬프트.md`)대로 만들면 모두 들어 있습니다.

| 표지 | 단원 파일에서 |
|---|---|
| 카드 색 | `:root`의 `--main` — 단원마다 다른 색으로 |
| 카드 부제 | `<header class="banner">제목<small>…</small>` 의 제목 |
| 차례 칩 | `<div class="zone" data-toc="짧은 이름">` (없으면 띠의 `<b>` 글자) |
| 빈칸 수 | 퀴즈 빈칸 `data-q="…"`의 개수 |
| 카드 제목 | `build.mjs`의 `NAMES`. 7단원처럼 새 번호는 파일 이름에서 가져옴 |
